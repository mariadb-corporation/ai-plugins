Learning Paths

Four routes through the tutorials. Pick the one that matches what you are trying to do rather than how experienced you are — the levels describe the material, not you.

Not sure which one?

Three questions that usually settle it.

"I just installed this and want to see it work."

Take First Steps. Three short tutorials, one throwaway server, and by the end you will know which half of the plugin does what.

Go to First Steps

"My schema has to survive being deployed twice."

Take The Schema Lifecycle. It is the difference between a create script and something you can ship version 2 of to servers still running version 1.

Go to Schema Lifecycle

"Something is already broken and I need to know why."

Take Operate and Optimize. Reading an unfamiliar schema, rehearsing changes on a throwaway server, and getting a real answer out of EXPLAIN rather than a guess about indexes.

Go to Operate and Optimize

"I need an API, or I need to get off MySQL."

Take Build an API, or Move off MySQL. The two largest things the plugins automate end to end, and the two with the most MariaDB-specific detail to get wrong.

Go to Build and Move
